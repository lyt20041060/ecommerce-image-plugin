一键提取商品图片

点击详情页右下角「获取图片」，集中查看普通图片、已进入页面的懒加载图片和 CSS 背景图片。

商品页面→获取图片→图片图库
先展开详情并滚动加载，再提取更完整。
⌁

智能过滤

自动去重，过滤疑似图标、Logo、占位图和小尺寸图片，让候选素材更清晰。

⊞

图片预览

新标签页展示图片与尺寸，点击查看大图，下载之前先确认。

✓

自由勾选

单张选择、全选或反选，实时查看选中数量，只保存需要的素材。

⇩

批量 PNG 下载

统一转换为 PNG，按「商品图_001.png」编号；显示下载进度和失败详情。

整页提取可能包含推荐商品，请预览后筛选。需要登录或受防盗链限制的图片可能无法转换，插件会提示失败原因。

开始使用

四步，把助手装进 Chrome

无需构建，无需注册。
下载、解压，然后加载。

  1. 01

    下载并解压插件

    下载本页的 ZIP 压缩包，解压到固定文件夹。确认文件夹内包含 manifest.json。

    下载 v1.0.0 ↓
  2. 02

    打开扩展管理页面

    把下面的地址粘贴到 Chrome 地址栏，然后按 Enter。

    chrome://extensions/

  3. 03

    开启开发者模式

    在扩展管理页面右上角打开「开发者模式」，显示本地加载选项。

    开发者模式
  4. 04

    加载已解压的扩展程序

    点击同名按钮，选择解压后包含 manifest.json 的文件夹。刷新商品页面即可开始。

    加载已解压的扩展程序
安装后怎么用？

正常登录商品页面 → 展开并滚动详情 → 点击「获取图片」→ 预览勾选 → 下载 PNG。下载时请保持图库标签页打开。
